# RobotAXController / Dự án Phần mềm điều khiển tay gắp hàng trục X cho máy ngoại quan hàng tự động

### Goal / Muc tiêu: Giao diện Winform net10 trên Laptop điều khiển MCU ESP32S3 stepper motor driver TB6600 điều khiển trục X tay gắp Robot Arm EEZY MK2. Sử dụng module cảm biến hồng ngoài LM393 để di chuyển đến điểm gắp thả hàng, scan inscpect hàng bằng scanner ESP32CAM. OK thì thả vào hộp OK, không OK thì thả vào hộp NG. Robot Arm điều khiển bằng 3 servo: 2 servo MG996R, gripper servo MG90S.
